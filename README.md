# Rebotics Products — Product Development Unit

Website for `products.rebotics.in`.

## Included
- Home / Product Development overview
- Research & Development page
- Product Lines / portfolio page
- Sector applications page
- Development Process page
- Project enquiry page
- Responsive CSS and mobile navigation
- No external image assets required

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files while keeping the same structure.
3. Enable GitHub Pages from the repository's Pages settings.
4. Add `products.rebotics.in` as the custom domain.
5. At your DNS provider, create a CNAME:
   `products` → `<your-github-username>.github.io`
6. Enable HTTPS after DNS is active.

## Before launch
Replace the demo enquiry form behavior in `script.js` with Formspree, a backend endpoint, Google Forms, or your preferred form service. Add your official contact details and social links.
